Add MCP servers

An MCP server gives Naseem new tools: your Blender scene, your Google Cloud projects, a database, another app. Connectors in Settings cover the popular services with one click. This guide is for everything else: any server you find can be added by hand in a minute.

العربية

1. Add any server

  1. Open Settings → MCP and press Add Server.
  2. Paste the server's config into the Server JSON box.
  3. Press Save. A green dot and a tool count mean it is connected.

Most servers publish a config for Claude, Cursor, VS Code or Codex. That same snippet pastes into Naseem unchanged, one server or several at once.

Tip: leave Require approval for this server's tools on for a server you don't know yet. Naseem then asks before each of its tools runs.

2. Servers with a web address

A hosted server needs only its address:

{
  "mcpServers": {
    "my-server": { "url": "https://example.com/mcp" }
  }
}

If the server offers a browser sign-in, a Sign in button appears on its row. You sign in with the service in your browser, and Naseem keeps the sign-in in your Mac's Keychain.

3. Servers that run on your Mac

Many servers are small programs that Naseem starts for you. Their config has a command instead of an address:

{
  "mcpServers": {
    "my-server": {
      "command": "npx",
      "args": ["-y", "some-mcp-package"],
      "env": { "SOME_KEY": "value" }
    }
  }
}
  • npx comes with Node.js.
  • uvx comes with uv.

Install the one the server asks for, once. The first connect can take a minute while the server downloads. A server on your Mac has no Sign in button in Naseem: it uses the account you are already signed in to on the Mac, or a key you put under env.

4. Recipe: Blender

Ask about the open scene, change it, render, and search Blender's manual, using Blender's own MCP server from Blender Lab.

  1. In Blender 5.1 or later, open Preferences → Get Extensions, add the repository https://lab.blender.org/, then install and enable the MCP add-on.
  2. In the add-on's preferences, start its server with the button there. It should say Server is running.
  3. Install uv if you don't have it.
  4. In Naseem, add this server:
{
  "mcpServers": {
    "blender": {
      "command": "uvx",
      "args": [
        "--from",
        "git+https://projects.blender.org/lab/blender_mcp.git#subdirectory=mcp",
        "blender-mcp"
      ]
    }
  }
}

Blender must be open with its server running whenever you use these tools. If you changed the port in Blender's preferences, add this line to the config with your values:

"env": { "BLENDER_MCP_HOST": "localhost", "BLENDER_MCP_PORT": "9876" }

Keep approval on: this server can run Python code inside Blender.

5. Recipe: Google Cloud

Run gcloud commands from a chat: projects, compute instances, storage, IAM and services.

  1. Install the gcloud CLI and sign in once in Terminal with gcloud auth login.
  2. Install Node.js if you don't have it.
  3. In Naseem, add this server:
{
  "mcpServers": {
    "gcloud": {
      "command": "npx",
      "args": ["-y", "@google-cloud/gcloud-mcp"]
    }
  }
}

The server acts as the account your gcloud CLI is signed in to.

6. When it doesn't connect

  • The command was not found. Install Node.js for npx or uv for uvx, then press Reconnect.
  • The first connect failed or timed out. The server was still downloading. Press Reconnect once.
  • Green dot, but the tools fail. The server is running without an account. Sign in where the server expects it: the Sign in button for a hosted server, the service's own tool for a server on your Mac.
  • Naseem asks before every tool. That is Require approval. Turn it off in the server's Edit sheet once you trust the server.
  • A popular service is not here. Look in Settings → Connectors first: those need no config at all.
