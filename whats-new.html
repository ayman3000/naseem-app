Naseem 1.4.25

LatestSep 11, 2026

New in 1.4.25

  • Routines — walk Naseem through a Mac task once and it offers to save the sequence, with named inputs. Replaying one runs every step with no model turn in between: the same TextEdit task, 8 calls / 75 s → 1 call / 32 s. Approvals still apply to each step.
  • A Routines tab in the brain inspector, and independent reads now run together within a turn.

Faster in 1.4.25

  • Reading a window is about twice as fast — one request for all of an element's attributes instead of eleven — and keyboard shortcuts are effectively instant.

Safer in 1.4.25

  • Your database is copied aside before any change to its shape, and once a day otherwise. Settings → General → Database backups shows the last copy and reveals the folder. Nothing is ever restored automatically.

Release notes are read live from GitHub Releases. Naseem requires macOS 14 or later.
