Naseem 1.4.6

LatestSep 4, 2026

New in 1.4.6

  • Quiet rules — a rule reaches you only on a finding: a download that failed, a backup that didn't appear. All-clear runs stay silent.
  • Rules must look before they speak — no "all clear" without actually running the check.
  • Dry run — see what a rule would do without changing anything.
  • Telegram, reliably — results reach your phone after a relaunch, and a connection blip no longer drops a message.
  • A friendlier rule editor — bigger prompt box and plain-language examples.

Release notes are read live from GitHub Releases. Naseem requires macOS 14 or later.
