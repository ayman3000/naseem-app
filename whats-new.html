What's New

Every Naseem release, newest first. The app updates itself; you can also download the latest DMG.

Naseem 1.16.0

LatestOct 3, 2026

Naseem makes images.

New in 1.16.0

  • Create and edit images (Pro). Ask for a logo, banner, illustration or any picture, in any words or language, and Naseem makes it. Ask for changes and it edits the image it made, or one you attach.
  • Use what you already have. Signed in with ChatGPT? Images come from your subscription, with no key and no extra bill. Or use your OpenAI or Google key. Pick in Settings → Models → Image model, or per chat from the model menu.
  • Images right in the chat. Each image appears under the answer with the model that made it, and is saved to your Outputs folder and Artifacts.

Fixed in 1.16.0

  • More honest answers after reopening a chat. Naseem now remembers what each earlier reply actually did, so a model can’t claim it ran something it didn’t. If an answer names an image that doesn’t exist, Naseem says so.

Naseem 1.15.4

Oct 2, 2026

Faster, lighter, steadier.

New in 1.15.4

  • Conversations open in under a second, however long they are. The model menu used to be rebuilt every time a chat opened; now it’s built only when you click it.
  • Replies are easier to read. Each answer starts with Naseem’s name, like your own messages start with “You”, and ends with Copy, Read aloud, the model that wrote it and how long it took, right where you finish reading.
  • Long chats stay quick. Very long conversations show the newest messages first; one click, “Show earlier messages”, brings up the rest.
  • Project roadmaps keep dates. Each task now records the day work started and the day it was finished, so “what got done this week” has an answer.

Fixed in 1.15.4

  • The chat view no longer goes blank, freezes or jumps, including in long conversations and after sending a second prompt. It now follows the newest content the way the system intends.
  • Less memory on long and image-heavy chats. Screenshots in the conversation are kept as small previews instead of full-size pictures.

Naseem 1.15.3

Oct 2, 2026

Claude is back to work.

Fixed in 1.15.3

  • Claude can get things done again. Claude models kept stopping halfway, unable to run commands or open files. They now work through your tasks the way they should.
  • You can see what Naseem is doing. While a longer step runs, like building an app, the chat now shows exactly what’s running and for how long, instead of a vague “Thinking…”.
  • Saved files open in the side panel. Files Naseem creates in your home folder now show their contents in the Artifacts panel instead of “couldn’t read file”.

Naseem 1.15.2

Oct 2, 2026

The transcript stays put.

Fixed in 1.15.2

  • The transcript no longer goes blank or freezes after a reply or a new message. The conversation view had a layout loop that could stall the app from the third message on; it now follows the newest content the way the system intends.

Changed in 1.15.2

  • Naseem now requires macOS 15 or later. Macs on macOS 14 keep 1.15.1.

Oct 1, 2026

A small fix for fresh installs.

Fixed in 1.15.1

  • The MCP settings tab shows Add Server when no server is set up yet. The button used to sit below the window on a fresh install.

Naseem 1.15.0

Oct 1, 2026

Z.ai, and Claude that thinks.

New in 1.15.0

  • Z.ai (GLM) is a provider. Paste a Z.ai key, pick your plan’s endpoint, and chat with GLM-5.3 and its siblings, with reasoning effort and vision.
  • Claude reasons now. Claude 4.6 and later think before answering, as much as your effort level allows.
  • The model menu fits on screen. One submenu per provider, and every set-up provider lists its models the first time you open it.

Fixed in 1.15.0

  • Long Claude answers are no longer cut off at 4,096 tokens.
  • A Z.ai balance error explains what to do.

Naseem 1.13.10

Sep 29, 2026

New in 1.13.10

  • Leaner messages. Naseem now sends only the tools a chat needs; Calendar, documents, Slack and automation tools load when you ask for them.
  • Project chats start informed. Your project’s rules (AGENTS.md, CLAUDE.md or naseem/rules.md) and notes come loaded, so work starts right away instead of re-reading them.
  • Your notes are safe. Naseem’s automatic roadmap and journal updates only add and move items — they never delete anything.
  • Checks that really ran. If your project declares a gate command, Naseem runs it before calling the work done.
  • Clearer changes. The Changes card shows what’s committed, and lists apart any files someone else changed while it worked.
  • Asks before risky git commands. Stash, checkout, restore, clean and rebase now ask first, even in chats that run without asking.
  • Skills bring their tools. A skill that names the tools it needs loads them with it.

Fixed in 1.13.10

  • GPT-5 models with your OpenAI key. They now work with tools and your chosen effort; the model list shows only chat models, and GPT-5.6 appears as Sol, Terra and Luna.
  • Fewer failed edits. A simpler edit tool and clearer error messages mean far fewer retries.
  • No more endless thinking. A step that only thinks for 10 minutes is told to act.

Naseem 1.13.0

Sep 21, 2026

New in 1.13.0

  • Slack. Ask what happened in a channel overnight, find the thread about the pricing change, see who asked about the release date. Naseem reads Slack as you, so it sees the channels you are in and nothing more, and there is no bot to invite anywhere. Posting is written in the conversation first and asks you every time, even in a chat set to run without asking — everyone in the channel sees it and it cannot be taken back. How it works. (Pro)
  • Each project keeps its own memory. What Naseem learns inside a project — a decision, a convention, the order you want things done in — is filed under that project and brought back when you open it. What it learns about you stays with you everywhere. The Memory tab shows what is filed where, and every line can be moved in either direction. Nothing moved when you updated. How it works.
  • The same PDF is only ever read once. Two helpers working on the same document now share what the first one extracted, instead of each doing the work again.

Fixed in 1.13.0

  • Stop stops. Pressing stop while Naseem was inside a long step used to wait for that step to finish before it took effect. It now takes effect the moment you press it. Quitting no longer waits either: it saves what was written so far and closes.
  • The transcript holds still. On models that call a dozen tools at once, the conversation could flash blank and back again while the steps landed. It stays where you are now, and tells you how many tools are running.
  • Reading a file no longer costs more than it should. Naseem used to fetch long files in very small pieces — cheap-looking, and in fact the most expensive way to read, because every step re-sends the whole conversation. Ordinary files now come back in one go.
  • Your Python is judged by the Python that will run it. A file Naseem wrote could be rejected as damaged when it was perfectly good, because it was being checked against the version of Python macOS ships rather than the one Naseem actually uses. And a genuine mistake now says what is wrong instead of asking for the same thing again.

Naseem 1.12.0

Sep 20, 2026

New in 1.12.0

  • Documents are read once. Point Naseem at a folder of proposals, specifications or reports and it reads each file a single time, writing notes you can open yourself: what the document is, the facts that matter with the page or slide they came from, and the questions it leaves open. Everything afterwards works from those notes, so the same file is never read twice and a long PDF does not fill the conversation. Read it again tomorrow and it costs nothing.
  • A model chosen for reading. Settings ▸ Models has a Reading model: pick something with a long context and a low price, or a local model to keep the document on your Mac entirely. Leave it alone and Naseem picks a sensible one for you.
  • A skill for starting from documents. Give Naseem a folder and a mission and it reads everything, writes the project description and the first three steps, then stops and asks you the questions only you can answer.
  • Skills are yours to choose. The skills Naseem ships with now start switched off, because a skill changes how Naseem works and not just what it knows. Turn on the ones that match your work; two are marked as recommended, and one button turns those on. Every run names the skill it followed under the reply, where one click turns it off again.
  • A Privacy chapter, in the manual and in the app: what stays on your Mac, everything that ever leaves it, and why. The full policy is one click from Settings.
  • Integrations fold away. Each one is a card showing its state at a glance, and a new button at the bottom sends the developer the integration you actually need.

Fixed in 1.12.0

  • Naseem no longer treats documents like code. Asking it to read a folder of files used to pull in a code-review procedure, split the work between helpers and read the same document several times over. It now reads them properly, once.
  • Helpers are no longer handed tools they cannot use. A helper working on a model that cannot see images is no longer given an image to look at, and a helper that fails says so plainly instead of reporting success.
  • Documents come back even when the reading model thinks too long.

Naseem 1.11.0

Sep 20, 2026

New in 1.11.0

  • Your Mac's apps. Turn them on one at a time in Settings ▸ Integrations ▸ Apple apps, and then just ask: what's on today, what came in this morning, find that note, remind me tomorrow at nine. Naseem uses the apps already on your Mac, with every account they sync — Gmail and Outlook included — so there is no account to connect and no key to paste. Nothing is fetched from the internet by Naseem, and nothing leaves your machine. How it works. (Free)
  • Reading never asks; changing always does. Listing your events or searching your notes changes nothing, so Naseem gets on with it. Creating an event, adding a reminder or writing a note asks first. Deleting asks every time, even in a conversation set to run without asking, and so does sending an email — which is why Naseem would rather open a draft in Mail for you to send.
  • ElevenLabs voices by language. Choose English or Arabic and the voice list follows, with the stock voices that speak every language kept beside the ones native to it. Browse ElevenLabs' Voice Library from inside Naseem and add a voice to your account in a click. (Pro)
  • Integrations, tidied. Each one is a card you can fold away, with its state on the header at a glance: what's on, what's connected, what has no key yet.

Fixed in 1.11.0

  • Naseem says when something is switched off instead of quietly doing it another way. Asking for a reminder while Reminders is off no longer puts an appointment in your calendar.
  • The Voice chapter appears in the manual. It shipped in 1.10.1 but never showed up in the list.

Naseem 1.10.1

Sep 19, 2026

New in 1.10.1

  • Send by pausing. With Send after a pause on (Settings ▸ Voice ▸ Listening), going quiet for a few seconds sends your dictation — with a countdown under the composer for the last second. Saying Naseem still works, and is now its own switch too.
  • A Voice chapter in the manual, covering speaking, dictating, the two ways to send, and voices — read it here.

Fixed in 1.10.1

  • Naseem no longer hears itself. The microphone rests while Naseem answers and speaks, then comes back on its own for your next message — also when you stop the voice early.
  • Settings search now finds the voice options by words like "pause" and "reply aloud".

Naseem 1.10.0

Sep 18, 2026

New in 1.10.0

  • Naseem speaks. Every reply has a speaker button, and Settings ▸ Voice has a new Reply aloud switch: turn it on — or click the speaker icon in the toolbar — and Naseem reads each reply as it finishes, in the reply's own language. Choose whether it reads the opening or the whole thing. Code and tables are never read out.
  • Talk instead of typing. Click the microphone and speak. It keeps listening until you click it again, and what it hears lands in the composer for you to read. End with the word Naseem and the message sends on its own — a whole conversation with your hands free. Your voice is recognised on your Mac when the language allows it, and Naseem tells you when it isn't.
  • Hear when a run finishes. With Speak a summary when Naseem isn't in front on, a run that ends while you're in another app tells you what it did — one sentence, never over you while you read.
  • ElevenLabs voices, with your own key. Switch the engine in Settings ▸ Voice, paste your ElevenLabs key, and pick from their voices or your own cloned ones. The key stays in your Keychain; every sentence is billed to your ElevenLabs account, never to Naseem. (Pro)
  • Settings, reorganised. A sidebar of eight panes with one search box that finds any setting by name. The Pro status sits in the footer, always in view.
  • Knowledge inspector: bigger, larger text, and MCP tools grouped by server.

Fixed in 1.10.0

  • The microphone now asks for permission. Earlier versions never showed the macOS prompt, so Naseem could not be allowed to hear you.
  • Key fields in Settings are bordered and read left to right, with the cursor where you expect it.

Naseem 1.9.0

Sep 18, 2026

New in 1.9.0

  • Attach Word, PowerPoint and Excel files. Drop a .docx, .pptx or .xlsx on the composer and ask about it, the same way you already can with a PDF. Slides and sheets are labelled, so answers say where they came from, and spreadsheets come back as tables you can read. Naseem 1.8.0

Sep 17, 2026

New in 1.8.0

  • Attach a PDF and ask about it. Drop a document on the composer, or pick it with the paperclip. Naseem reads only the pages your question needs, so a long report costs you nothing until it's actually opened — and answers cite the page they came from, so you can check them.
  • Scanned documents, read on your Mac. A PDF that's really a photograph of paper has no text inside it at all. Naseem reads it anyway, in thirty languages including Arabic, using macOS itself — the document never leaves your machine. Read once, it's instant every time after. (Pro)
  • Charts and diagrams. When the answer is in a picture rather than in words — which quarter was strongest, where a flowchart branches — Naseem can look at the page instead of only reading it. It asks you first, every single time, and names the page and what it will cost. (Pro)
  • Documents belong to the project. Attach a contract in one chat and the next chat in that project already knows it's there. The same file attached again is still one file on disk.
  • Attachments show in the Artifacts pane, so a document stays one click away after the conversation has scrolled on — with a preview inside Naseem.

Fixed in 1.8.0

  • An approval no longer freezes the window. It used to be a dialog over everything: on the Tasks board, one chat asking a question stopped every other chat until you answered. Approvals now wait quietly in the conversation that raised them, with an Allow for this conversation option for the ones you're tired of confirming.
  • Approvals say what they're approving — "Look at page 2 of report.pdf?" — with the exact details one click away.
  • Anything that spends money always asks, even in a conversation set to run without asking, and the card explains why it stopped.
  • Saved images are named for what they show rather than after the tool that produced them.
