MCP Servers

Any MCP server

Connect Model Context Protocol servers (web search, Canva, chrome-devtools, …) from Settings → MCP; their tools bridge straight into your chats.

Setup

  • Settings → MCP → add a server (stdio or HTTP) — or paste a whole JSON config into the editor.
  • Server secrets/env are stored in the Keychain.
  • Each server has its own require-approval toggle (on by default).
