Get Started

Welcome to Naseem

A fast, native macOS AI agent — chat with any major AI model or fully on-device, and let it safely act on your Mac: run commands, manage files, drive the iOS Simulator, and automate Mac apps, all behind a human-in-the-loop approval gate.

First launch

  • Open Settings (⌘,) → General — pick a default provider and model.
  • Providers — paste API keys for cloud providers. Keys live in the macOS Keychain, never in plaintext.
  • Prefer local? Choose MLX for fully on-device inference (weights download on first use), or Ollama if you run ollama serve.
  • Start chatting — or tap one of the start cards a new chat offers. They fill the composer with a task Naseem can do right now; edit it or send it. Try Reclaim disk space to see the tool-approval flow.
Bring your own AI key — cloud models bill your API key directly; local Ollama/MLX models are free.
