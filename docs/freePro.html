Free vs Pro

Free is the agent you chat with and supervise. Pro is the agent you hand work to. No account either way — you bring your own API keys, and Pro is one payment, not a subscription.

The two plans

Free

$0 · no account, no card
  • Every provider with your own keys — Anthropic, OpenAI, Gemini, OpenRouter, Ollama Cloud, local Ollama, on-device MLX
  • Conversations, search, vision, files and artifacts
  • Up to 3 projects
  • All five built-in profiles
  • Terminal, filesystem, Python and PDF tools, behind approval
  • MCP servers, memory, built-in skills, ⌥Space Quick Ask
  • Share, copy and export any conversation as Markdown
  • Usage & Cost: tokens, cost and memory footprint

Naseem Pro

one-time · up to 3 Macs
  • Everything in Free, plus:
  • iOS Simulator driving — build, install, tap, type, read the screen
  • Mac computer use — drive native apps through Accessibility
  • Rules — run a prompt on a schedule, quietly
  • Sub-agent delegation, and a cheaper model to run them on
  • A review model that checks the answer before you see it
  • Telegram remote, with approvals on your phone
  • Unlimited projects and custom profiles
  • Self-improving skills

Good to know

  • Every install starts with a 14-day full-feature trial — no card. When it ends, the app keeps working on Free; it never locks you out.
  • Nothing is taken away. Projects you already made keep working whatever the plan; the limit applies only to creating new ones.
  • Profiles are not locked. All five are on Free — inside Software Engineer, QA Engineer and Automation/Ops, only the Simulator- and Mac-driving capabilities are Pro, and the agent says so precisely when a request needs one.
  • No model bill from us. Pro pays for what Naseem can do, not for the models. You keep using your own keys, and local models cost nothing at all.
  • The Free feature set may change in future versions. A version you already have never loses features it shipped with.
