إضافة خوادم MCP

خادم MCP يمنح نسيم أدوات جديدة: مشهد Blender المفتوح، مشاريعك على Google Cloud، قاعدة بيانات، أو تطبيقًا آخر. «الموصِّلات» في الإعدادات تغطي الخدمات الشائعة بنقرة واحدة. هذا الدليل لكل ما عداها: أي خادم تجده يمكن إضافته يدويًا في دقيقة.

English

١. إضافة أي خادم

  1. افتح Settings ← MCP واضغط Add Server.
  2. الصق إعداد الخادم في مربع Server JSON.
  3. اضغط Save. النقطة الخضراء وعدد الأدوات يعنيان أن الخادم متصل.

معظم الخوادم تنشر إعدادًا جاهزًا لـ Claude أو Cursor أو VS Code أو Codex. الإعداد نفسه يُلصق في نسيم كما هو، لخادم واحد أو لعدة خوادم معًا.

نصيحة: اترك خيار Require approval for this server's tools مفعّلًا مع أي خادم لا تعرفه بعد، فيسألك نسيم قبل تشغيل كل أداة من أدواته.

٢. خوادم لها عنوان على الويب

الخادم المستضاف يحتاج عنوانه فقط:

{
  "mcpServers": {
    "my-server": { "url": "https://example.com/mcp" }
  }
}

إذا كان الخادم يتيح تسجيل الدخول عبر المتصفح، يظهر زر Sign in في صفّه. تسجّل الدخول لدى الخدمة في متصفحك، ويحفظ نسيم تسجيل الدخول في سلسلة مفاتيح جهازك.

٣. خوادم تعمل على جهازك

كثير من الخوادم برامج صغيرة يشغّلها نسيم لك. إعدادها يحتوي أمرًا بدل العنوان:

{
  "mcpServers": {
    "my-server": {
      "command": "npx",
      "args": ["-y", "some-mcp-package"],
      "env": { "SOME_KEY": "value" }
    }
  }
}
  • npx يأتي مع Node.js.
  • uvx يأتي مع uv.

ثبّت ما يطلبه الخادم مرة واحدة. قد يستغرق أول اتصال دقيقة ريثما يُنزَّل الخادم. الخادم الذي يعمل على جهازك ليس له زر Sign in في نسيم: يستخدم الحساب المسجَّل به على الجهاز أصلًا، أو مفتاحًا تضعه تحت env.

٤. وصفة: Blender

اسأل عن المشهد المفتوح، عدّله، أخرِج صورة، وابحث في دليل Blender، عبر خادم MCP الرسمي من Blender Lab.

  1. في Blender 5.1 أو أحدث، افتح Preferences ← Get Extensions، أضف المستودع https://lab.blender.org/، ثم ثبّت إضافة MCP وفعّلها.
  2. في تفضيلات الإضافة شغّل خادمها بالزر الموجود هناك. يجب أن تظهر عبارة Server is running.
  3. ثبّت uv إن لم يكن لديك.
  4. في نسيم، أضف هذا الخادم:
{
  "mcpServers": {
    "blender": {
      "command": "uvx",
      "args": [
        "--from",
        "git+https://projects.blender.org/lab/blender_mcp.git#subdirectory=mcp",
        "blender-mcp"
      ]
    }
  }
}

يجب أن يكون Blender مفتوحًا وخادمه يعمل كلما استخدمت هذه الأدوات. إذا غيّرت المنفذ في تفضيلات Blender، أضف هذا السطر إلى الإعداد بقيمك:

"env": { "BLENDER_MCP_HOST": "localhost", "BLENDER_MCP_PORT": "9876" }

أبقِ الموافقة مفعّلة: هذا الخادم يستطيع تشغيل كود Python داخل Blender.

٥. وصفة: Google Cloud

شغّل أوامر gcloud من المحادثة: المشاريع، الأجهزة الافتراضية، التخزين، IAM والخدمات.

  1. ثبّت gcloud CLI وسجّل الدخول مرة واحدة في Terminal بالأمر gcloud auth login.
  2. ثبّت Node.js إن لم يكن لديك.
  3. في نسيم، أضف هذا الخادم:
{
  "mcpServers": {
    "gcloud": {
      "command": "npx",
      "args": ["-y", "@google-cloud/gcloud-mcp"]
    }
  }
}

يعمل الخادم بالحساب المسجَّل به في gcloud على جهازك.

٦. إذا لم يتصل

  • لم يُعثر على الأمر. ثبّت Node.js من أجل npx أو uv من أجل uvx، ثم اضغط Reconnect.
  • فشل أول اتصال أو انتهت مهلته. كان الخادم ما زال يُنزَّل. اضغط Reconnect مرة واحدة.
  • النقطة خضراء لكن الأدوات تفشل. الخادم يعمل بلا حساب. سجّل الدخول حيث يتوقع الخادم: زر Sign in للخادم المستضاف، وأداة الخدمة نفسها للخادم الذي يعمل على جهازك.
  • نسيم يسأل قبل كل أداة. هذا خيار Require approval. أوقفه من نافذة Edit للخادم حين تثق به.
  • خدمة شائعة غير مذكورة هنا. ابحث أولًا في Settings ← Connectors: تلك لا تحتاج أي إعداد.
